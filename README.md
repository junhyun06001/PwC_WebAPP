# PwC_WebAPP

2026 PwC 신규입사자 Pre-boarding 프로그램 조별 웹앱 프로젝트입니다.

## 구조

```
PwC_WebAPP/
├── index.html   # 메인 페이지
├── style.css    # 스타일
└── script.js    # 앱 로직
```

빌드 과정 없는 정적 HTML/CSS/JS 앱입니다. `index.html`을 브라우저로 열면 바로 실행됩니다.

## 배포

GitHub 저장소를 Vercel(Hobby 플랜)에 연결해 배포합니다. `main` 브랜치에 push하면 자동으로 재배포됩니다.

## 협업

저장소 Settings → Collaborators에서 조원을 초대합니다. API 키 등 비밀값은 저장소에 올리지 않습니다.
